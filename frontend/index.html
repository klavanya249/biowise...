    PROJECT GUIDE

    How BIOWISE AI works

    A simple overview of the application workflow and its current estimation method.

    01

    Collect input data

    Enter feedstock type, daily quantity, water content, retention time, temperature, pH and organic loading rate.

    02

    Estimate production

    The backend applies an illustrative feedstock-yield factor and operating-condition adjustments to calculate an indicative estimate.

    03

    Check conditions

    Rule-based checks flag pH, temperature, loading and moisture values that may need attention.

    04

    Save and learn

    Store each estimation in Supabase PostgreSQL and review previous results on the dashboard.

    TRANSPARENCY

    What does “AI” mean in this MVP?

    This first version does not train or run a machine-learning model. It uses a transparent, rule-based calculation so that the application works without paid APIs or a trained dataset. The calculation is a software prototype only; its feedstock factors and adjustment ranges are illustrative assumptions, not scientific constants.

    Future improvement: Replace the illustrative estimator with a regression or other machine-learning model trained and validated on a sufficiently large, reliable biogas dataset. Compare predictions with actual measured gas output and report model error before using it for decisions.
